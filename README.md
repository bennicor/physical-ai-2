# Практика 2: настройка обучения PandaPickCube

В каждом запуске менялся ровно один параметр, результат сравнивался с baseline по двум метрикам: `mean_reward` на обучении и SR (success rate) на инференсе по 10 эпизодам.

## Результаты

| Эксперимент       | Изменение                                        | mean_reward | SR (k/10) |
| ----------------- | ------------------------------------------------ | ----------- | --------- |
| baseline          | -                                                | 1424.28     | 10/10     |
| max_iters_500     | `MAX_ITERS = 500`                                | 1272.82     | 8/10      |
| box_target_strong | `box_target = 40.0`                              | 4323.03     | 9/10     |
| qpos_strong       | `robot_target_qpos = 30.0`                       | 4538.77     | 0/10      |
| box_target_weak   | `box_target = 4.0`                               | -      | -      |

Эксперимент `box_target_weak` не удалось провести, из-за того, что после изменения параметра `box_target` на итерациях от 100 до 200 возникала ошибка, связанная с тем, что одна из компонент награды становится `NaN`.
